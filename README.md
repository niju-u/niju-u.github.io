# Jestin Villegas — Portfolio

Personal portfolio and resume of Jestin Villegas, web developer in Cebu City, Philippines.

Plain HTML, CSS and JavaScript — no build step and no dependencies.

- `index.html` — portfolio
- `resume.html` — resume (printable A4)
- `assets/Jestin-Villegas-Resume.pdf` — resume PDF
- `assets/css`, `assets/js`, `assets/img` — styles, interactions and images

## Updating the resume PDF

The phone number is kept off the public pages and is only added when exporting the PDF:

1. Open `resume.html#phone=<number with country code, digits only>` in Chrome or Edge.
2. Print → Save as PDF, margins **None**, background graphics **on**.
3. Save over `assets/Jestin-Villegas-Resume.pdf`.

Hosted with GitHub Pages. Any push to `main` updates the live site within a minute or two.
